# ChatGPT 그림 제작 가이드

해양수산도감 웹앱(`site/`)에 들어갈 생물 그림 235장을 ChatGPT로 만드는 방법입니다.

## 한눈에 보기
| 항목 | 내용 |
|---|---|
| 만들 그림 | 주요 수산물 235종, 1종당 1장 |
| 참고 데이터 | `site/images/image_list.csv` (이름·학명·분류·그리는 방향·생김새) |
| 붙여 넣을 프롬프트 | `site/images/prompts/batch_01.md` ~ `batch_24.md` (10종씩, 마지막 묶음 5종) |
| 최종 규격 | **960×720 px, 4:3, WebP 품질 82, 1장 120KB 이하** |
| 파일 이름 | `{ID}.webp` (예: 광어 = `270000012842.webp`) |
| 올릴 위치 | GitHub `hosang78/susan` 저장소, 브랜치 `ccr-60c32675-asli89`, 폴더 `site/images/` |

960×720은 화면에 보이는 크기(목록 72px, 상세 최대 280px 폭)의 3배 이상이라 고해상도 휴대폰에서도 선명하고, 용량은 작게 유지됩니다.

## 진행 순서
1. ChatGPT에서 새 대화를 엽니다(그림 생성과 코드 실행이 되는 모델).
2. `prompts/batch_01.md` 내용을 **전부** 복사해 붙여 넣습니다.
3. ChatGPT가 10장을 그린 뒤, GitHub에 쓸 수 있으면 저장소에 바로 커밋하고, 안 되면 `batch_01.zip`을 줍니다. 마지막에 확인 표를 줍니다.
4. 표의 "확인 필요 사항"을 읽고, 이상한 그림은 같은 대화에서 다시 그려 달라고 합니다(예: "3번 다시: 지느러미가 설명과 달라").
5. zip을 받았을 때만 직접 올립니다(아래 "직접 올리는 방법").
6. 다음 묶음은 **새 대화**에서 `batch_02.md`로 반복합니다. 대화가 길어지면 스타일이 흐트러지기 쉽습니다.

## 직접 올리는 방법 (zip을 받았을 때, GitHub 웹·휴대폰 가능)
1. `github.com/hosang78/susan` → 브랜치를 `ccr-60c32675-asli89`로 바꿉니다.
2. `site/images` 폴더로 들어가 **Add file → Upload files**를 누릅니다.
3. WebP 파일들을 올리고 커밋합니다. 파일 이름은 절대 바꾸지 마세요.
4. 올린 뒤 Claude에게 "그림 올렸어"라고 알려 주세요. `python3 site/tools/prepare_images.py`를 실행해 규격 검사와 화면 반영(`data/images.json` 갱신)을 합니다.

ChatGPT가 WebP 변환을 못 하고 PNG만 줬다면, 파일 이름만 `{ID}.png`로 맞춰 같은 폴더에 올리세요. `prepare_images.py`가 4:3 자르기, 960×720 변환, WebP 저장을 대신 해 줍니다.

## 짧게 요청하는 방법 (ChatGPT가 저장소를 읽을 수 있을 때)
묶음 파일을 붙여 넣는 대신 아래 한 줄만 보내도 됩니다.

> GitHub `hosang78/susan` 저장소 브랜치 `ccr-60c32675-asli89`의 `site/images/prompts/batch_01.md` 파일을 읽고, 그 안의 규칙과 목록대로 그림을 만들어 줘.

## 용량
- 1장 120KB 이하 × 235장 = 최대 약 28MB, 보통 15~20MB 예상입니다.
- GitHub 무료 계정 제한(파일 1개 100MB, 저장소 권장 1GB 이하, GitHub Pages 사이트 1GB 이하)에 비해 충분히 작습니다.
- 같은 그림을 여러 번 고쳐 올리면 이전 버전도 저장소 기록에 남으니, 확인 후 한 번에 올리는 편이 좋습니다.

## 묶음 파일에 들어가는 공통 규칙
아래 표시 사이의 글이 모든 `batch_XX.md` 앞부분에 그대로 들어갑니다. 규칙을 고치려면 여기를 고친 뒤 저장소 최상위에서 `python3 site/tools/build_data.py`를 실행하세요.

너는 "해양수산도감" 웹앱의 생물 그림 담당이야. 아래 규칙을 정확히 지켜서, 목록에 있는 생물마다 그림을 1장씩 만들어 줘.

### 1. 근거 자료
- 각 생물의 이름·학명·분류·생김새는 아래 목록에 적힌 내용만 근거로 삼아. 이 내용은 국립해양생물자원관 「해양생물종정보 서비스」 원문을 쉬운 말로 정리한 것이야(GitHub `hosang78/susan` 저장소의 `site/images/image_list.csv`).
- 생김새 설명에 있는 색·무늬·지느러미·가시·껍데기 특징은 빠짐없이 반영해.
- 설명에 없는 부분은 그 학명의 실제 생물에 맞는 일반적인 모습으로 그리고, 없는 무늬나 색을 지어내지 마.
- 설명과 학명 사이에 확신이 없으면 그리되, 마지막 표의 "확인 필요 사항"에 적어.

### 2. 그림 스타일 (모든 그림 동일)
- 정확하고 깔끔한 과학 도감 일러스트: 가는 윤곽선과 부드러운 수채화풍 채색. 사진처럼 보이게 하지 마.
- 생물 1개체만, 몸 전체가 잘리지 않게. 여러 마리, 사람, 손, 도구, 요리·손질된 모습은 금지.
- 배경: 무늬 없는 아주 연한 회청색 단색(#F2F6F6). 물·바닥·바위·해초 같은 서식지 배경, 그림자, 테두리, 액자 없음.
- 글자, 숫자, 이름표, 화살표, 워터마크, 서명 없음.
- 생물이 가로 폭의 약 80%를 차지하게 가운데 배치하고, 상하좌우 여백을 고르게 둬. 작은 섬네일(가로 72px)로 줄여도 형태가 알아보이도록 윤곽을 분명하게.
- 방향은 목록의 "그리는 방향"을 따라. 묶음 안의 모든 그림은 빛 방향·채색 톤·선 굵기를 똑같이 맞춰.

### 3. 출력 규격 (반드시 지켜)
1. 그림은 가로형(4:3에 가장 가까운 가로 비율)으로 생성해.
2. 생성 후 코드 실행(Python)으로 아래처럼 변환해:
   - 가운데 기준으로 4:3 비율로 자르기 → 960×720 px로 리사이즈(LANCZOS) → RGB로 바꿔 WebP 품질 82로 저장.
   - 파일 하나가 120KB를 넘으면 품질을 5씩 낮춰 다시 저장(최저 65).
3. 파일 이름은 목록의 `파일명` 그대로 써(예: `270000012842.webp`). 이름을 바꾸거나 한글 이름을 붙이지 마.
4. 1종씩 차례로 그리고, 전부 그린 뒤 한꺼번에 변환해. 중간에 멈추면 몇 번까지 끝났는지 알려 줘.
5. 저장 방법 (둘 중 가능한 쪽):
   - **GitHub에 쓰기 권한이 있으면:** 저장소 `hosang78/susan`, 브랜치 `ccr-60c32675-asli89`의 `site/images/` 폴더에 WebP 파일만 추가해 커밋해. 커밋 메시지는 `Add illustrations batch {BATCH}`. 다른 파일은 절대 수정·삭제하지 말고, 새 브랜치나 PR을 만들지 말고, 같은 이름의 파일이 이미 있으면 덮어쓰기 전에 나에게 물어봐.
   - **쓰기 권한이 없으면:** WebP 파일을 `batch_{BATCH}.zip` 하나로 묶어 내려받기 링크를 줘.
6. 마지막에 어느 방법으로 저장했는지 말하고 아래 표를 만들어 줘.

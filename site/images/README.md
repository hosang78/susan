# 그림 넣는 방법

그림이 없으면 화면에 "그림 준비 중" 자리만 보입니다.

## 그림 규격
- 가로세로 비율 **4:3**, 크기 **480×360 px**
- 형식 **WebP** (용량 1장 40KB 이하 권장)
- 화면에서는 목록 72px, 상세 최대 280px 폭으로 작게 보입니다.

## 파일 이름
- `image_list.csv`의 `파일명` 그대로 저장합니다. 예: 광어(넙치) → `270000012842.webp`
- 이 폴더(`site/images/`)에 넣은 뒤 저장소 최상위에서 `python3 site/tools/build_data.py`를 실행하면 `data/images.json`이 갱신되어 화면에 나타납니다.

## 그림 요청 문장 예시 (ChatGPT 등)
`image_list.csv`의 한 줄을 넣어 요청하세요.

> 해양 생물 도감용 작은 일러스트를 그려줘. 대상: {흔한 이름}({국명}, 학명 {학명}). 생김새: {생김새}. 옆모습 전체가 보이게, 아주 연한 단색 배경, 글자·워터마크 없음, 단순하고 정확한 도감 스타일, 가로 4:3 비율 480×360px.

생성한 그림은 실제 생물과 다를 수 있으니 생김새 설명과 비교해 확인하세요.

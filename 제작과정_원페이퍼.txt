해양수산도감 제작 과정 (원페이퍼)
작성일: 2026-11-08 / 저장소: github.com/hosang78/susan (브랜치 ccr-60c32675-asli89)

1. 개요
- 주요 수산물 235종을 휴대폰에서 찾아보는 웹 도감입니다.
- 국립해양생물자원관이 공공데이터포털(data.go.kr)을 통해 제공하는
  「해양생물종정보 서비스」 공공데이터를 이용해 만들었습니다.
- 설명 정리와 앱 개발은 Claude(Anthropic, Claude Code)가,
  생물 그림 생성은 ChatGPT(OpenAI)의 이미지 생성 기능이 맡았습니다.

2. 사용한 데이터
- 출처: 국립해양생물자원관 「해양생물종정보 서비스」(공공데이터포털 오픈API)
- 내려받은 날: 2026-11-07 (기준일)
- 전체 22,703종 중 수산 관련 8개 그룹 8,498종을 사용
  (어류, 조개류, 고둥·전복류, 오징어·문어류, 새우·게류, 해삼·성게류, 멍게류, 해조류)
- 같은 종도 목록 조회와 종별 조회의 내용이 달라 두 가지를 모두 받아 합침
- 앱은 API를 실시간으로 부르지 않고, 내려받은 자료를 파일로 담아 사용
  (인증키 노출 방지, 호출 제한·서버 장애와 무관하게 동작)

3. 제작 단계
 ① 데이터 수집: 공공데이터 API로 전체 목록과 종별 원문 3,441종을 내려받음
 ② 분류: 그룹, 국내 해역(동해·서해·남해·제주·전 연안), 정보 충실도(상·중·하)를 자동 분류
 ③ 주요 종 선정: 시장·현장에서 많이 쓰는 수산물 235종을 고르고 흔한 이름을 붙임
    (예: 넙치→광어, 조피볼락→우럭, 우렁쉥이→멍게)
 ④ 쉬운 설명 작성(Claude): 235종의 원문을 일반인이 읽기 쉬운 말로 다시 정리
    - 원문에 없는 내용은 넣지 않음, 설명 속 숫자를 원문과 자동 대조
    - 원문끼리 다르거나 의심스러운 점은 검수 메모로 따로 표시
 ⑤ 엑셀 정리: 본 파일(주요수산물 235종, 그 외 3,206종, 전체 목록 8,498종)과 원문 파일
 ⑥ 웹 앱 개발(Claude): 검색, 그룹·해역 필터, 종별 상세, '원문 보기'(원문 그대로 표시),
    하단 출처·주의 문구, 다크 모드, 휴대폰 화면 최적화
 ⑦ 그림 생성(ChatGPT): 종별 이름·학명·생김새를 담은 프롬프트로 도감 일러스트 235장 생성
    - 규격: 960×720px(4:3), WebP, 1장 평균 약 37KB (전체 약 9.4MB)
    - 사진처럼 보이지 않는 도감 일러스트 스타일, 글자·배경 없음
    - Claude가 규격과 원문 생김새를 대조 검수 (2종은 다시 그리기 후보)

4. 결과물 위치
- 웹 앱: site/ (index.html, app.js, style.css, data/, images/)
- 엑셀: output/해양수산도감.xlsx, output/해양수산도감_원문.xlsx
- 그림 프롬프트·가이드: site/images/CHATGPT_가이드.md, site/images/prompts/
- 재생성 스크립트: site/tools/, work/

5. 주의 사항
- 종별 설명은 원문을 쉽게 다시 정리한 것으로 국립해양생물자원관의 공식 견해가 아니며,
  원문은 각 종 화면의 '원문 보기'에서 확인할 수 있습니다.
- 흔한 이름은 참고용으로 붙인 것이라 검수가 필요합니다.
- 효능·약용 정보는 원문 기재 내용이며 의학적 효과를 뜻하지 않습니다.
  금어기 등 법령 정보는 최신 법령을 확인해야 합니다.
- 그림은 AI(ChatGPT)로 생성한 일러스트로 실제 생물과 다를 수 있습니다.
- 데이터는 2026-11-07 기준이며 자동 갱신되지 않습니다.

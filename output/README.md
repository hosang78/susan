# 해양수산 도감 데이터

출처: 국립해양생물자원관 해양생물종정보 서비스(공공데이터포털). 기준일 2026-11-07.
수산 관련 8개 그룹 8,498종(전체 22,703종 중)을 가공했습니다.

## 파일
| 파일 | 내용 |
|---|---|
| `해양수산도감.xlsx` | 본 파일 (안내, 주요수산물, 그외종_설명, 전체목록, 분류기준, 용어풀이) |
| `해양수산도감_원문.xlsx` | 원문(수정 없음). 목록조회본과, 내용이 다른 경우 단건조회본 |

## 시트
- **주요수산물 (235종)**: 쉬운 설명을 새로 풀어 쓴 시트. 원문에 없는 내용은 넣지 않았고, 원문끼리 다르거나 의심스러운 점은 `검수 메모`에 적었습니다.
  - 6종(연어, 임연수어, 소라, 진주담치, 재첩, 왕게)은 원문에 설명이 없어 분류 정보만 있습니다.
- **그외종_설명 (3,206종)**: 용어풀이 시트의 사전으로 전문용어를 괄호 설명으로 자동 변환한 시트. 문장을 사람이 다듬은 것이 아니며, 몸 크기·지느러미 수 같은 계측 문장 일부는 뺐습니다.
- **전체목록 (8,498종)**: 이름, 분류, 해역, 정보 충실도, 설명이 들어 있는 시트 이름.
- **분류기준 / 용어풀이**: 그룹·해역·충실도 규칙, 지명→해역 표, 전문용어 사전(177개).

## 주의
- `흔한 이름`(광어, 우럭 등)은 일반 지식으로 수동 지정한 것이라 검수가 필요합니다.
- 해역은 국내분포 글에서 자동 분류했고, 해역 이름이 없으면 지명으로 추정했습니다(`해역 근거` 열 참고).
- 효능·약용 정보는 원문 기재 내용이며 의학적 효능을 보장하지 않습니다. 금어기 등은 최신 법령을 확인하세요.
- 복어류는 독이 있는 부위가 있습니다.
- 사진은 없습니다.
